# Movie Storage Directory

Place your downloaded movie file here!

## Supported Formats
- `.mp4` (Recommended, H.264 / AAC for maximum browser compatibility)
- `.webm` (VP8/VP9 / Opus)
- `.mkv` (Supported by modern browsers with compatible codecs)
- `.mov`

## How it works:
1. When you place a movie file here (e.g. `movies/my-movie.mp4`), the **K-FLIX** website will automatically detect it.
2. It will appear right on the hero banner as your hosted film.
3. Clicking **Play** will stream it instantly with smooth seeking, ±10s skip, timeline scrubbing, and settings!
4. You can also drag-and-drop or select any movie file directly from the website UI without manually moving files.
